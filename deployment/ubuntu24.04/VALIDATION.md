# Ubuntu 打包验收记录

本文件是模板，未执行的项目不得填写“通过”。复制到服务器每轮的 `reports/<run-id>/VALIDATION.md` 后填写。报告不得包含密码、Token、模型 API Key、bootstrap-token 或私钥。
