# 团队办公室

## 范围与入口

Web 与 Electron 使用 `packages/app-ui` 的同一套组件。在现有聊天页顶部增加「对话 / 办公室」胶囊切换按钮，默认仍为对话。原聊天页面的布局、主题、输入、队列、审批和停止功能保留。办公室只展示当前会话，不聚合其他会话，不创建另一套运行时。手机界面本次不增加入口。

## 数据与交互

- 当前 Agent 对应当前直接会话。伙伴名单从 `agent-management.snapshot` 的授权关系读取，不把首页展示关系当成调用授权。曾实际参与本会话的受派 Agent 仍可查看。
- 角色代表 Agent，任务卡代表一次委派。点击工位或侧栏团队成员（侧栏收起时在场景下方），查看任务、完整报告、执行记录及产物。多次委派通过任务选择器切换。
- 新委派：调用方走到受派者工位，气泡展示真实任务文本，然后返回自己的工位。
- 执行中：受派者在自己的工位工作；气泡展示公开 commentary、工具进展或待回答问题。推理流不用于气泡，也不额外请求模型生成台词。
- 完成：受派者走到调用方身边，气泡展示真实报告，然后返回工位。
- 动画按队列依次播放；后台任务保持原有并行语义。即使任务先于动画完成，详情和状态立即展示最新事实。
- 人物行走使用独立透明帧图集：侧身四帧迈步与摆臂，正面/背面交替迈步，左行镜像右行。按路线累计距离在通道拐点切换朝向；位移和帧动画由同一 requestAnimationFrame 时钟推进，长帧限制步长，隐藏后暂停、恢复后连续移动。人物按 Agent ID 保持挂载；任务抢占或取消时从当前位置接入原有通道，走到目标后再切换姿势。委派双方到位后才开始交代，返回工位后才结束交接；空闲行程也以实际到达事件结束，不使用独立的行走倒计时。
- 失败、取消、中断会清理该任务的动画；角色回到工位，真实终态保留可查看。
- 等待用户时，办公室右侧展示现有待办组件，仍调用同一回答/审批命令；新出现的待答复委派自动选中相关伙伴。详情关闭时待办保留在场景下方。对话模式仍在输入区显示待办，不新增授权语义。
- 首次快照作为基线，刷新、切换会话、重新进入办公室不会播放历史交接。动画只消费后续新增或变化的委派事实。
- 减少动态效果模式下不播放行走，仍展示交接气泡。窄窗口使用可收起的浮层详情，场景可以滚动。
- 空闲角色错峰去咖啡角、沙发或窗边，休息后沿通道返回工位；每个休息点同时只容纳一个角色。空闲动作默认启用，遵循系统减少动态效果偏好。
- 空闲动作仅为本地展示，不调用模型、不写任务记录。执行、等待用户、等待授权或等待交接的角色优先留在任务流程；新任务立即结束休息展示。隐藏页面、卸载场景及减少动态效果时停止空闲计时。
- Agent 之间的真实闲聊留待后续交互协议接入，本版不生成模拟聊天记录。

## 结构

`packages/app-ui/src/components/office/`：

| 模块                                    | 职责                                         |
| --------------------------------------- | -------------------------------------------- |
| AgentOffice                             | 入口、场景与详情组织                         |
| OfficeScene                             | 房间、工位及路径呈现                         |
| OfficeAgent / OfficeDesk / OfficeBubble | 人物、家具、消息气泡                         |
| OfficeInspector                         | 任务选择、报告、执行过程和产物               |
| OfficeActivityLog                       | 最近的真实委派动态                           |
| office-model                            | 领域投影到 UI 状态的纯函数                   |
| office-layout                           | 固定工位坐标与通道路线                       |
| office-choreography                     | 事件去重、交接队列、取消清理                 |
| office-idle / use-office-idle           | 空闲活动、位置占用、任务抢占与计时           |
| OfficePerson                            | 人物图集、头像、坐姿与休息姿势               |
| OfficeWalkPerson / office-walk          | 行走图集、逐帧姿势、按距离切换朝向           |
| office-movement / use-office-movement   | 当前位置续走、通道重规划、位移与姿势共用时钟 |
| OfficeTaskTimeline                      | 委派与执行步骤的真实事件时间线               |
| use-office-data                         | 授权名单、受派会话订阅和选中任务             |
| use-office-animation                    | 本地动画阶段与计时器生命周期                 |
| office.css / assets                     | 办公室专属样式、背景素材                     |

共享 `use-session-projection.ts` 负责快照、cursor 增量、重复事件过滤、缺口重同步、重试和订阅销毁。办公室与原有委派执行详情复用它。UI 只依赖 `@client-contracts` 与已注入的 `AgentClientApi`；没有修改服务端委派规则、数据库或工具协议。

背景和透明人物 PNG 随 Vite 构建进入 Web 和 Electron 包。2026-09-26 按用户参考图对齐：房间比例 1000:660，四个基础工位、中央白板、左侧书架与沙发、右侧咖啡角；家具在背景内，人物、选中框、名牌、消息与椅背遮挡为独立 SVG / HTML 层。超过四位成员时扩展可滚动工位。生成方式及完整提示词记录在 `assets/README.md`。

办公室模式使用约 16% 的团队侧栏、约 22% 的任务详情栏和中间主场景。根据最新界面要求，移除办公室侧栏品牌文字、顶部「团队办公室」标题介绍和任务概览栏（含其按钮）；保留顶部视图切换与连接状态。输入框直接复用对话页的宽高、内边距及自动增高规则，在场景列居中，窄窗口按可用宽度收缩。侧栏样式仅在办公室挂载时生效，原对话视图保持原样。待确认卡和执行时间线只显示真实会话数据，不填入参考图的演示任务。

## 验收

- 单元：历史不重播、单批快速完成、并行委派去重、失败/取消/中断清理、交互恢复、路线、公开说明与推理隔离。
- 运行时回归：现有委派集成测试与聊天显示策略测试。
- `node scripts/verify-office.mjs`：临时 Runtime + 本地确定性模型 + 正式 Web / Electron 构建，验证真实 HTTP / SSE 事件、交接、待办、报告、刷新、窄窗口、失败与取消。
- `node scripts/verify-office.mjs --live http://127.0.0.1:4317`：显式使用现有 Agent、授权和模型，在独立验收会话执行一次给定数据的只读协作任务。不会修改 Agent 配置。
- 截图与结果保存在 `test-results/office/`，fixture 与 live 分开；测试脚本关闭自己启动的浏览器、桌面窗口及临时服务，不关闭 live 服务。

运行环境使用项目支持的 Node 22+（本次 Node 24）。实际验收结论以生成的 `report.json` 为准。
