# 阶段 4.7.5：多智能体档案与会话归属测试用例

- 状态：专项验收进行中；核心用例已有自动化执行证据，未宣称全部 P0/P1 已通过。
- 更新日期：2026-09-07；回归基线：阶段 1～4.7.0。
- 对应设计：[4.7.5 架构设计](阶段4.7.5-多智能体档案与会话归属开发架构设计.md)。

## 1. 测试目标与方法

验证同等级 Agent 直接问答与授权调用、Session 单 Driver、私有浅层 MD、唯一 builtin-memory 定义的多作用域实例，以及 Skill/MCP/Node/Python 复用。

P0 为归属、安全、迁移、并发和恢复，失败阻断；P1 为管理与主要交互，原则上阻断；P2 为容量与细节，失败需评估。委派使用脚本化模型；进程生命周期使用真实 stdio Fixture 和受控时钟；存储使用当前打包 Memory MCP。不能以名称不同替代数据隔离断言。

Fixture：fresh-two-users（含新注册）、agent-bindings（三 Agent 同资源）、three-memory-scopes（一个定义两私有一共享）、lifecycle-server（延迟/崩溃/Schema 变化）、delegation-star（A→B，B 报告后 A→C）、running-step、many-agents（30 Agent 各 100 会话）。本地 4.7.5 启用前已清空旧会话；不再把旧事件回放兼容作为本阶段目标。
