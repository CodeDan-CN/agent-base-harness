## 1. 测试目的

本文档只验证阶段 4 新增或改造的能力：

- models.dev 精简目录的生成、校验、解析和离线使用。
- DeepSeek/百炼预制、思考开关、思考强度和实际 Adapter 请求。
- DeepSeek reasoning replay 与工具循环。
- 首 Step 80% 压力判断、Session 历史摘要、当前 Event Context 替换，以及 Harness Pruner、Checkpoint、Surface Replace 和 Provider overflow recovery。
- 模型字段与 Compaction Event/Projection 的数据库升级和重建。
- 新能力在长 ConversationEvent、长 Turn、大 Tool Result、多 Session 和双用户后台执行中的正确性。

不重新建立通用 Provider/Skill 兼容矩阵，不执行全面 Chaos、安全审计、性能水位和发布候选质量报告。

| S4-I08 | P1     | 两个用户使用不同容量但相同远程 Model ID | 各自按本用户 Snapshot 触发压缩，目录和缓存不交叉                       |

这些用例不设置面向整个产品的 P95 性能水位。只断言新能力有界：压缩次数不超配置、overflow 最多重试一次、无持续自旋、无明显资源泄漏和跨用户写入。
